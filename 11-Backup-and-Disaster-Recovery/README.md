# 11 — Backup & Disaster Recovery

Recover predictably, not heroically.

## Topics

- Logical backups with `pg_dump` / `pg_dumpall`
- Physical backups with `pg_basebackup`
- Continuous archiving and WAL
- Point-in-time recovery (PITR)
- Backup verification and restore drills
- Retention, encryption, and offsite strategy
- RPO/RTO planning

## Layout

- `notes/` — backup strategy and runbooks
- `examples/` — dump/restore commands
- `labs/` — complete a PITR exercise
- `pg_dump/` — logical backup assets
- `pg_basebackup/` — physical backup assets
- `pitr/` — archiving and recovery assets
