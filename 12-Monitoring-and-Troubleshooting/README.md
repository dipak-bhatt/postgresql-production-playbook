# 12 — Monitoring & Troubleshooting

See problems before users do, then resolve them fast.

## Topics

- Key metrics: connections, TPS, latency, cache hit ratio, bloat
- `pg_stat_*` views and `pg_stat_statements`
- Wait events and lock inspection
- Logging configuration and slow query logs
- Alerting thresholds and dashboards
- Common incidents: bloat, wraparound, replication lag, disk full

## Layout

- `notes/` — metric references and diagnosis guides
- `examples/` — monitoring queries
- `labs/` — incident simulations
- `queries/` — saved diagnostic SQL
- `runbooks/` — step-by-step incident response
