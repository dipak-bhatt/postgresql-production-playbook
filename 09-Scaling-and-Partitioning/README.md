# 09 — Scaling & Partitioning

Grow beyond a single table or node without losing operability.

## Topics

- Declarative partitioning: range, list, hash
- Partition pruning and maintenance automation
- Time-series and retention strategies
- Read replicas and read/write splitting
- Sharding approaches and consistency trade-offs
- Citus and distributed PostgreSQL
- Connection scaling and pooling

## Layout

- `notes/` — scaling patterns and limits
- `examples/` — partition and shard setups
- `labs/` — implement partitioning end-to-end
- `partitioning/` — partition-specific scripts
- `sharding/` — sharding designs
- `citus/` — Citus experiments
