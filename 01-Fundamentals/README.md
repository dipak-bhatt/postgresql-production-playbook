# 01 — Fundamentals

Core PostgreSQL concepts every production engineer should know.

## Topics

- Installation, versions, and release cadence
- Databases, schemas, tables, roles, and search_path
- Data types (numeric, text, temporal, JSON/JSONB, arrays, ranges, UUID)
- DDL and DML essentials
- Constraints: PK, FK, UNIQUE, CHECK, EXCLUDE
- `psql` workflow, meta-commands, and `\timing`
- Configuration basics (`postgresql.conf`, `pg_hba.conf`)

## Layout

- `notes/` — concept explanations and cheat sheets
- `examples/` — small runnable SQL demos
- `labs/` — exercises with expected outcomes
