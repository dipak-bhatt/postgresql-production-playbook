# 06 — Security & Row-Level Security

Harden access, protect data, and enforce per-tenant visibility.

## Topics

- Roles, groups, `GRANT`/`REVOKE`, and ownership
- `pg_hba.conf`, SSL/TLS, and authentication methods
- Principle of least privilege and separation of duties
- Row-Level Security policies and `BYPASSRLS`
- Column-level security and views
- Auditing: `pgaudit`, logging, and event triggers
- Secrets management and encryption at rest

## Layout

- `notes/` — auth models and policy design
- `examples/` — role and RLS setups
- `labs/` — implement tenant isolation
