# 18 — Scripts & Tools

Reusable utilities for day-to-day PostgreSQL work.

## Topics

- `psql` meta-command recipes and `.psqlrc`
- Bash automation for backup and maintenance
- Python tooling (`psycopg`, migrations, checks)
- Monitoring and health-check SQL
- Migration helpers and verification scripts
- Safe, idempotent scripting practices

## Layout

- `psql/` — psql scripts and rc files
- `bash/` — shell automation
- `python/` — Python utilities
- `sql/` — reusable diagnostic SQL
- `migrations/` — migration templates and runners
