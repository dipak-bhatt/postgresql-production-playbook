# 13 — Production Best Practices

Operational discipline for running PostgreSQL safely.

## Topics

- Configuration management and change control
- Migration safety (locking, zero-downtime DDL)
- Capacity planning and storage growth
- Connection management and pooling
- Naming, ownership, and documentation standards
- Upgrade planning and major-version migrations
- On-call checklists and game days

## Layout

- `notes/` — standards and rationale
- `examples/` — well-configured templates
- `labs/` — audit an instance against a checklist
- `checklists/` — pre-launch and review checklists
