# 17 — Docker & Deployment

Package, run, and automate PostgreSQL deployments.

## Topics

- Official images and initialization scripts
- Docker Compose for local and test stacks
- Persistent volumes and backup considerations
- Configuration and secrets injection
- Kubernetes: StatefulSets, Operators, PVCs
- Ansible and infrastructure-as-code
- CI/CD migration pipelines

## Layout

- `notes/` — deployment patterns and cautions
- `examples/` — runnable local stacks
- `labs/` — deploy and operate a stack
- `docker/` — Dockerfiles and entrypoints
- `compose/` — Compose files
- `kubernetes/` — manifests and Helm values
- `ansible/` — provisioning playbooks
