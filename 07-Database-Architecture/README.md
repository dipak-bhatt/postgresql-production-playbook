# 07 — Database Architecture

Design schemas that stay maintainable and fast as they grow.

## Topics

- Normalization vs. deliberate denormalization
- Schema, table, and naming conventions
- Keys: natural, surrogate, UUID vs. bigint
- Modeling hierarchies, time-series, and audit tables
- Soft deletes, event sourcing, and CQRS
- Migration strategy and versioned schema changes
- Referential integrity trade-offs

## Layout

- `notes/` — modeling patterns and trade-offs
- `examples/` — reference schemas
- `labs/` — design and critique a schema
