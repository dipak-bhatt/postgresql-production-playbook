# 02 — Advanced SQL & CTEs

Expressive SQL for complex reporting and data transformations.

## Topics

- Window functions (`OVER`, `PARTITION BY`, frames)
- Common Table Expressions and `MATERIALIZED`
- Recursive CTEs and graph-style traversal
- `LATERAL` joins and `DISTINCT ON`
- Aggregations, `FILTER`, `GROUPING SETS`, `ROLLUP`, `CUBE`
- JSON/JSONB querying and path expressions
- `RETURNING`, upserts (`ON CONFLICT`), and `MERGE`

## Layout

- `notes/` — syntax guides and patterns
- `examples/` — one query per concept
- `labs/` — progressively harder query challenges
